# Project Title: Budget Tracker

## Project Description

This is a simple beta program that helps users start their budgeting journey.

Features

- Enter user income and expenses  
- Calculates the user’s expenses  
- Shows total remaining money  
- Shows total money spent  
- Shows total income

## How to Run the Program

1. Make sure you have Python installed.  
2. Open the link [https://onlinegdb.com/UCSP\_kl5C](https://onlinegdb.com/UCSP_kl5C)   
3. Click on “Fork” on the top right.  
4. Click on “Download Current File.”  
5. Run the program by pressing F5 or clicking 'Run'  
6. Follow the on-screen instructions to enter user inputs.
